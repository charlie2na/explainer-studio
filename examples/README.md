# Included example

`from-idea-to-film/` is the curated sample. Run `npm run sample` to install an
editable copy under `videos/`. Repeating the command preserves an existing copy.
It includes six narrated scenes, three images, word timings, and speech cues.
It needs no API key, Whisper installation, or voice regeneration to preview or export.

The artwork was generated using Codex's image-generation tool; prompts are in
`artwork-prompts.json`. The prerecorded demo narration was generated with macOS
`say`, with word timing estimated by local Whisper. The audio files can be played
on macOS and Linux; generating new demo narration requires macOS.
