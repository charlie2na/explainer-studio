# Frame Studio implementation contract

Node 20 ESM, vanilla browser JS, Node HTTP server. Project root contains lib/, public/, scripts/, videos/. No framework required. Browser renderer is deterministic and reusable for studio and Playwright capture.

Project JSON (videos/<id>/project.json): {id,title,createdAt,updatedAt,revision:1,brief:{audience,takeaway,duration:60,format:'landscape',style,tone},voice:{provider:'demo'|'elevenlabs',voiceId:'',model:'eleven_multilingual_v2'},scenes:[{id,title,narration,duration:10,layout:'title'|'image'|'steps'|'quote',visualPrompt,asset:null|string,items:[],audio:null|string,words:[{word,start,end}],timingSource:'estimated'|'whisper'|'elevenlabs'}],reviews:{brief:null,script:null,storyboard:null,animation:null},references:[],exports:[]}. Paths for asset/audio are relative to project directory, e.g. assets/scene-01.png. Word times local to scene. Sequential scenes; total duration sums scene durations. Asset URL /media/<projectId>/<relative path>. Export record {file,createdAt,revision,width,height,fps}. Reviews contain {revision,at}. On content save increment revision and invalidate reviews/exports freshness as appropriate. Assets referenced by path, no data URL in saved scenes.

HTTP API: GET /api/projects -> {projects:[full project]}; GET /api/projects/:id -> project; POST /api/projects JSON {title,brief} -> project; PUT /api/projects/:id full project -> saved project; GET /api/status -> {ffmpeg:boolean,whisper:boolean,elevenlabs:boolean,imageGeneration:'codex',...}; POST /api/projects/:id/review {stage} -> project; POST /api/projects/:id/upload {name,data(base64),kind:'reference'|'asset'|'audio',sceneId?} -> project; POST /api/projects/:id/jobs {type:'stills'|'render'|'speak'|'transcribe',sceneId?,provider?,width?,height?,fps?} -> {id,status}; GET /api/jobs/:id -> {id,status:'queued'|'running'|'done'|'error',progress:0..1,message,result?,error?}. GET /media/... public project media only. No secret served. POST same-origin only. Errors {error:string}.

Renderer public/renderer.js exports mountScene(container,project,time,{width,height,captions=true}={}) synchronous, drawing deterministic state for absolute seconds, and preloadProject(project) async for images/fonts. Uses relative same-origin /media. public/render.html loads ?project=id and exposes window.renderReady Promise and window.renderFrame(time), #frame container at requested width/height query defaults1280x720.

lib/render.mjs exports async renderProject({project,projectDir,baseUrl,mode='render',width=1280,height=720,fps=30,onProgress=()=>{}}) -> {file,files?,width,height,fps} paths relative projectDir. Stills generates contact sheet HTML and PNG beat snapshots; render outputs exports/video-<timestamp>.mp4 and captions SRT, mixes all scene audio with correct starts, optional project.music with volume. No server ownership. Playwright uses render.html. Keep all render outputs versioned.

lib/audio.mjs exports async speakProject({project,projectDir,sceneId,provider='elevenlabs',onProgress}) and transcribeProject({project,projectDir,sceneId,onProgress}); returns updated project (caller persists). Narration per-scene cache keyed text/settings; local demo via macOS say or explicitly silent fallback; never silently substitute paid providers. ElevenLabs env ELEVENLABS_API_KEY. whisper uses python command configurable WHISPER_PYTHON. lib/audio.mjs also exports async audioStatus() -> {ffmpeg,whisper,elevenlabs,demoVoice}. Provider errors helpful, no keys.

Parent owns server, persistence, CLI, docs/skill, integration tests, sample project. UI agent owns public/index.html, public/studio.js, public/style.css. Renderer agent owns public/renderer.js, public/render.html, lib/render.mjs and renderer tests. Audio agent owns lib/audio.mjs and audio tests. Do not edit others' files. Inform parent of contract changes.
